# Test Coverage & Suite Map — CricOS

## Overview
Automated regression tests are executed via `./pipeline.sh test --summary` (routed through `run_tests.sh` to `pnpm test` or native Node runner with `--experimental-strip-types`).
The test suite has been consolidated into 5 high-cohesion Domain Test Suites alongside 4 Baseline Integration Suites and 4 Playwright Visual/E2E Suites, maximizing test speed, eliminating redundancy, and strictly enforcing the Minimal Tokens Protocol.
